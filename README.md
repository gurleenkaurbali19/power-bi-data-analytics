# Power BI Analytics

Exploring data preparation, transformation, modeling, visualization, and interactive reporting using Microsoft Power BI.

## Overview

This project covers hands-on exploration of the Power BI data analytics workflow, from preparing and transforming data to building data models and creating interactive reports.

The work focuses on understanding how data can be cleaned, transformed, modeled, visualized, and presented effectively using Power BI.

## Data Preparation & Transformation

Data preparation and ETL were performed using Power Query, including:

* Importing data into Power BI
* Data cleaning and preparation
* Data type transformations
* Column transformations
* Creating and modifying columns
* Concatenating columns
* Preparing datasets for analysis
* Exploring different Power Query transformation capabilities
